## Final_Project_Power_BI

Data Sources and Attached Files

This repository contains the cleaned and processed files used for the Power BI project "Analysis of Labor Demand in Italy (2019–2024)".

## 📁 Included Files:

dati_originali_puliti.xlsx
Cleaned and processed version of the Excel file. Empty rows were removed, formats fixed, errors corrected, and data adapted for Power BI import.

progetto_finale_POWER.BI
Power BI project file containing the dashboard and visualizations.

progetto_finale.pdf
PDF version of the Power BI dashboard for static viewing.

🔗 [YouTube video link]: [https://youtu.be/AHPjJRROvZ8?si=T5YlJHcZnIQmc8z5
]
Video presentation of the project (~2:30 minutes), with a summary of the analysis and an explanation of the created visualizations.

## Notes

The original raw data files are not included in the repository due to size and data quality considerations.
Only the cleaned and processed data used in the project are provided.
